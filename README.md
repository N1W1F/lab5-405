# CPIT405 Lab 5 — NBA Player Stats

Open `index.html` in your browser. No installation required.

Includes dynamic DOM table rendering, search input event, dropdown change event, dark mode click event, click event delegation for sorting, row hover styling, player/teams counters, and an empty-state message.

Data is transcribed from the lab starter dataset, preserving the five statistics shown in the assignment table. Original starter also contains blocks and turnovers but they are not shown in the assignment table.

Deploy: upload index.html, styles.css, script.js to the root of your own GitHub repository, then Settings > Pages > Deploy from a branch > main > /(root) > Save. Submit the published Pages URL.
